Privacy Policy for PixelPomodoro

Effective Date: July 23, 2026

1. Overview

PixelPomodoro ("we", "our", or "the extension") is a cozy pixel-art productivity timer Chrome extension designed to help users manage work and break intervals. We are committed to protecting your privacy. This Privacy Policy explains our practices regarding user information.

2. Information Collection and Use

PixelPomodoro does not collect, store, transmit, or share any personal data or usage analytics.

All data generated by the extension—including:

  • Timer settings (work duration, break durations, auto-start options, sound preferences)
  • Productivity statistics (daily completed pomodoros, streaks, best streaks)
  • Unlocked achievements

is stored 100% locally within your browser using Chrome's built-in local storage API (chrome.storage.sync).

3. Network & External Connections

PixelPomodoro operates completely offline:

  • No data is sent to external servers.
  • No analytics, tracking scripts, or telemetry frameworks are included.
  • No remote code is loaded or executed.

4. Permissions

PixelPomodoro requests the following minimal browser permissions:

  • storage: Used solely to save user timer settings and statistics locally.
  • alarms: Used to run background countdown timers so sessions remain accurate when the extension popup is closed.
  • notifications: Used to display local desktop notifications when a work or break session completes.

5. Third-Party Sharing

We do not sell, rent, trade, or share any user data with third parties under any circumstances.

6. Contact Us

If you have any questions about this Privacy Policy, please contact the developer via the Chrome Web Store support page or project repository.
